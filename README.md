# K线道场 KLineDojo · 盘感训练 + 指数看板（本地网页版）

> 🥋 盘感是练出来的。真实历史行情双盲回放，逐根推演、模拟撮合，零风险磨手感。
> （原名「爆竹训练营」，致敬启发的「爆竹K线训练助手」）

四个模块：
- **训练**：双盲 K 线训练——随机/自选抽股、逐根回放、模拟买卖
- **指数看板**：18 个 A股/港美指数的全历史 K 线浏览器——日/周/月/年、MA/BOLL/MACD/KDJ/VOL、
  手动画线（趋势线/水平线/斐波那契/通道/矩形/文字，localStorage 按指数持久化）、
  简化缠论（笔+中枢+线段+背驰自动画）、图表模板
- **行情**（个股/ETF）：自选列表（与训练自选共用）+ 搜索添加；日线（baostock）+
  分钟 5/30（astock，限最近 4000 根）；前复权（锚定最新，与训练同口径）/不复权切换；
  画线/缠论/小地图/联动副图与指数看板同款；数据收盘后更新（标题显示数据截至时刻）
- **复盘历史**：每局结算自动保存完整复盘包（真实日期 K 线+买卖标记+交易明细+指标），
  开始页「📋 复盘历史」随时回看；支持单条删除/清空（中途结算的局标 ⏹）

**数据依赖**：个股/ETF 行情存于 `data/market/`（本项目自有副本，**不入库**），由
`bz_update.py` 用 **baostock**（免费无 token）**从零建立并维护**——全新克隆一条命令
`--bootstrap` 即可建库（含退市股）；海外指数走腾讯/Yahoo（`data/index/`）。
详见「数据与更新」章节。

## 快速开始（全新克隆三步走）

```bash
cd kline-dojo
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

.venv/bin/python bz_update.py --bootstrap      # 从零建库，单进程限速约一晚（可中断重跑续传）
.venv/bin/python server.py                     # 默认 8870 端口 → http://127.0.0.1:8870
```

嫌建库慢想先试玩：`--bootstrap --codes 600519,300750,510300,...` 只建指定标的（每个
标的抓全史，几分钟即可开练；日后跑全量 `--bootstrap` 自动补齐其余，互不冲突）。

Web 端零第三方依赖（标准库 http.server）；pandas/pyarrow 是服务端读 parquet 用，
baostock 是更新器用。数据根默认 `data/market/`，可用 `BZ_MARKET_ROOT` 环境变量改指。

自检（数据不变量断言，改完代码跑一下）：

```bash
.venv/bin/python server.py --selftest
```

## 训练参数

- 初始资金、可见历史根数、训练推进根数、起始/结束年份、上市年限、剔除 ST

  往前取（不足则用完为止，最少 40 根），结束日留空则到数据末尾。指定后年份区间

  印花税万X（默认万5，仅个股卖出）、过户费万X（默认万0.1，仅个股）；
  **成交模式**：当根收盘（默认）或次日开盘
- 训练页：`空格/→` 下一根，`P` 自动播放（0.5x–8x），`B` 买入，`S` 卖出，`F` 结算

## 交易规则（撮合引擎在前端 app.js）

- **成交价**：`当根收盘`模式=按 B/S 时眼前这根 bar 的收盘价即时成交；
  `次日开盘`模式=挂单，次一根 bar 开盘价成交（开盘一字涨停拒买/跌停拒卖、
  开盘价导致资金不足整单作废；最后一根 bar 无法挂单）
- **T+1**：当日买入冻结，次一交易日起可卖
- **涨跌停拒单**：指数无涨跌停（数据无该字段，自动不限制）
- **整手**：主板/创业板 100 股整数倍；科创板 ≥200 股可 1 股递增；ETF/指数 100 份
  整数倍；清仓可一次性卖出零股
- **费用**：见高级设置（默认佣金万1最低5元、印花税卖出万5、过户费万0.1，
  均仅个股；ETF/指数只收佣金）

## 指数看板

- **数据**：腾讯 ifzq `kline/kline`（A股 11 个 + 港 3 + 标普/纳指综合/道指）+ Yahoo chart
  （纳指100 `^NDX`，腾讯无其历史）。指数为价格指数无除权，单一源全历史无拼接跳空。
- **全历史**：启动时后台自动增量刷新（首次全量回填）；页面「⟳ 同步数据」手动同步

- **周期/指标**：日/周/月/年由日线在前端聚合（ISO 周）；**多面板布局**——K 线独占
  大面板，BOLL（竹线缩略+三轨，最矮）/VOL/MACD/KDJ 各占独立小面板，价格轴对齐、
  范围与十字光标联动；MA5/10/20/60 叠加主面板；图例随十字光标显示开启指标的当前值。
- **画线**：趋势线（两点）、水平线（一带价格标签）、**斐波那契回撤**（两点，
  0/23.6/38.2/50/61.8/78.6/100% 档位+价格标签）、**平行通道**（三点：基线两点+第三点
  定宽度）、**矩形区域**、**文字标注**、点击删除、撤销/重做（Ctrl+Z/Y）、清空；落点
  磁吸最近 bar 的 OHLC；按指数存 localStorage，切换周期时日期自动吸附到该周期最近
  的 bar。点击取最近 bar（v1.1 修复：此前点在两根 bar 之间会静默失败）。
- **图表模板**：周期+指标开关组合命名保存（看板/训练各自独立一套），一键应用。
- **小地图**：图表下方全历史收盘缩略条，高亮当前可视窗口；点击/拖动秒跳任意年代
  （30 年全历史翻页比滚轮快）。
- **联动副图**（⟷ 联动）：主图下方加一块副图，同标的不同周期（默认周K对照日K）或
  另选 18 指数之一对照；十字光标与可视范围随主图同步（按日期映射）。
- **缠论（简化版）**：K线包含合并 → 分型 → 笔（顶底交替+间隔≥4合并K）→ 中枢（三笔

  比较 MACD 柱面积 Σ|hist|，价创新高/新低而面积收缩即标记顶/底背驰）。当前周期数据上
  实时计算，"缠论/段/背"三个开关独立。

### 已知限制

- 各源历史起点以腾讯/Yahoo 实际提供为准：标普 1950 起、纳指综合 2007 起、道指 2009 起、
  沪深300 2005 起（早于这些的年份拿不到）
- 早期恒指等无成交量（volume=0）
- fqkline 端点高频请求会被腾讯限流 501，故全部走 kline/kline；Yahoo range=max 会降级，
  故按 period1/period2 分段拉取
- 训练会话存服务端内存：重启后未揭晓的会话 reveal 会失效（成绩已落盘不受影响）

## 已知简化（有意为之）

- 印花税固定用现代费率：按日期切换会向训练者泄露时间信息（费率本身已可配）
- 不限制成交量参与率（可吃掉当根全部成交量）
- ETF 不区分 T+0 品种（跨境/债券/黄金实际 T+0），统一按 T+1
- 个别 bar 缺涨跌停价的窗口已在服务端剔除；ETF 文件 schema 不一致已做兼容
- 次日开盘模式：挂单按当根收盘估算资金，开盘价高于估算时整单作废（不部分成交）
- 指数训练把指数当作可交易的"指数基金"（T+1、100 份整手），与真实股指期货/ETF
  交易规则不同

## 数据与更新（baostock）

行情自有副本在 `data/market/`，每标的 12 列：serving 10 列 + **amount（成交额）** +
**turnover_rate（换手率%）**，个股额外带 `is_st`（0/1）逐日列——量能数据完整。

1. **从零建库 `bz_update.py --bootstrap`**：逐年（最后一个交易日）`query_all_stock`
   快照并集发现全部标的——**含已退市股**（训练池无幸存者偏差；快照按日期过滤准确，
   实测 2000 年快照无 2001 年上市的茅台、有 2005/2010 年退市的齐鲁石化/邯郸钢铁）→
   **单进程串行**全量抓取（1990s 至今；baostock 每次调用 3-8s，全库约一晚）→
   用各标的本地首根 bar 回填上市日（免每标的一次 query_stock_basic）。
   `--codes` 可只建指定标的（试玩/补漏）。
   **抓取一律单进程 + 限速，绝不多进程**——baostock 对并发登录/高频请求会临时拉黑
   IP（10001011，几分钟到数小时自动解除）：整轮一次登录、快照间隔 8s、发过请求的
   标的间小睡 0.5s。**全程可中断重跑续传**（快照与抓取都有断点），若仍撞上限流，
   等解除后重跑同一条命令即可接着上次的进度继续。实测数据质量：与 tushare 副本
   比对，价格逐位一致、涨跌停 100% 吻合、因子比例一致（绝对量纲两源各自恒定，
   前复权只用比例，不受影响）
2. **日常维护 `bz_update.py`**（baostock 免费无 token，单进程限速）：
   - `--update`：增量追加全部在市标的（交易日历预判，无新交易日时全库零 API 调用、
     1 分钟跑完；有新交易日约 10-20 分钟）+ 自动发现回补新股/新 ETF +
     **A股 11 指数合流**到
     `data/index/`（与腾讯缓存同文件 append-only，量纲 股→手 已对齐；科创50 baostock
     无数据仍走腾讯）+ 海外指数照旧腾讯/Yahoo
   - `--extend-back`：**回补既有副本 2015 以前历史**（从 tushare 副本导入的老库用；
     `--bootstrap` 建的库天然全历史，无需此步）
   - `--backfill 代码`：单标的全量重拉
   - `--validate --sample 40`：抽样与官方值比对（自检口径漂移）
   - `--check-factors`：全库因子步长审计（每个除权日验证 因子步长 == 昨收/除权基准）

### 复权机制（重点）

- 本地存的是**累计后复权因子**：baostock `backAdjustFactor`（事件表），与 tushare
  `adj_factor` 同量纲——40 只抽样在重叠期**逐位一致**（含多次分红股）
- 训练一律**前复权、锚定窗口末根**（`bz_session._bars_payload`：窗口内
  `factor/末根factor` 等比缩放），跨源追加不破坏比例：写入前在重叠日做锚定对齐
- 增量时因子懒加载：`pre_close==昨收`（无除权）直接沿用末值，不拉事件表
- **可靠性边界**：1993 起每个除权步长均通过经济自洽校验（`--check-factors` 全绿）；
  1991-92 baostock 事件表被 0.5% 涨跌停年代的基准重置污染（如 000001 有 25 个假事件），
  因此**训练年份下界锁定 1993**。baostock 的前复权"序列"（adjustflag=2）在 ETF 早期
  另有一套归一，与事件表不符——我们采用事件表（已验证正确），不采用该序列

### 涨跌停价计算

1996-12-16 起有制度（此前 NaN）；主板 10%/ST 5%（**2026-07-06 起 ST 同 10%**，从官方
涨跌停价数据反推确认）、创业板 2020-08-24 起 20%、科创板 20%、注册制新股前 5 日不设限。
抽样 40 只与 tushare 官方值 100% 吻合。停牌日丢弃（与 tushare 口径一致）。

```bash
# 环境准备（本项目独立 venv）
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

.venv/bin/python bz_update.py --bootstrap            # 一次性：从零建库（全新克隆）
.venv/bin/python bz_update.py --update               # 日常（cron 也跑这个）
.venv/bin/python bz_update.py --validate --sample 40 # 抽样比对
.venv/bin/python bz_update.py --check-factors        # 因子审计
```

### 分钟线（本地挂接 astock；公开仓库不含数据）

- **本地**：与姊妹项目 astock（A股回测系统，`../astock`）同机部署时**自动挂接**其分钟
  副本 `data/parquet/mins/{code}/{freq}.parquet`（tushare `stk_mins`，5/30min，约 5600 只
  个股、起点 2015-01，ETF 无该源）；也可用环境变量 `BZ_MINS_ROOT` 指到任意同布局目录。
  只读挂接、不写入。API：`GET /api/mins/coverage?code=600519`（可用周期与覆盖范围）、
  `GET /api/mins/kline?code=&freq=&start=&end=&limit=`（返回
  `[ts,o,h,l,c,v,amount,adj_factor]`）。
- **GitHub 使用者**：仓库**不含任何分钟数据**（baostock 无分钟线；数据体量大且抓取
  凭证私有）。其余全部功能不依赖分钟数据。想接分钟线：自行抓取任意来源（tushare
  `stk_mins` 需 token/积分，或 akshare 等），按上述目录布局放 parquet（列：
  `trade_time,open,high,low,close,volume,amount`，**不复权原始价**，volume 单位股、
  amount 元），设 `BZ_MINS_ROOT` 即可。
- **复权口径（实证结论，000001/600519 全量比对）**：astock 分钟线是**不复权原始价**，
  与本项目日线同口径（开盘价逐位一致；tushare `adj_factor` 与 baostock
  `backAdjustFactor` 同量纲已另行验证）——服务端已按交易日把本项目日线的**累计后复权
  因子**映射进每根分钟 bar（`adj_factor` 列），训练用的前复权锚定算法（因子等比缩放）
  可直接套用，**跨源算法一致，无需二次处理**。
- **数据质量边界（与复权无关，须知晓）**：tushare 分钟线的 high/low **丢失盘中瞬间
  极值**（实证：600519 约 47% 交易日分钟聚合 high/low 比日线窄，最大差 19 元；日线
  high/low 以 baostock 为准，两边日线逐位一致）；约 10% 交易日分钟量能略缺。日内
  形态/量能训练可用，**不要用分钟聚合替代日线**。

页面开始页也有「⟳ 更新行情」按钮（`POST /api/market/update`，后台执行，完成自动生效）。

**自动更新（cron，收盘后跑）**：

```cron
30 1 * * 2-6  cd /path/to/kline-dojo && .venv/bin/python bz_update.py --update >> data/update.log 2>&1
```

已知口径差异（baostock vs tushare）：名称变更时间线 baostock 无（bootstrap 建库的
`names.parquet` 每标的一条、用快照名；揭晓显示历史名可能滞后，但 ST 判定用逐日
`is_st` 列，比名称匹配更准）；退市股上市/退市具体日期未逐只核对（随机池的年份过滤
用首根 bar 日期，天然准确）。

## 复盘与成绩管理（v1.3）

- **自动保存**：每局结算（含中途按 F 的局）时把完整复盘包落盘 `data/replays/*.json`——
